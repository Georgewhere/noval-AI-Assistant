# 本地 AI 小说助手 - 安装包

## 使用前必读

本安装包包含两部分：
1. **Ollama** - 本地大模型运行环境
2. **AI 服务端** - 让手机可以连接电脑的 AI

---

## 第一步：安装 Ollama（必须）

### 方法 A：一键安装（推荐）

双击运行 `1-安装-Ollama.bat`

### 方法 B：手动安装

1. 打开浏览器访问：https://ollama.com/download
2. 下载 Windows 版本
3. 运行安装程序

---

## 第二步：下载 AI 模型

### 方法 A：一键下载（推荐）

双击运行 `2-下载-模型.bat`

### 方法 B：手动下载

1. 按 `Win + R`，输入 `cmd`，回车
2. 复制粘贴：
   ```
   ollama pull qwen2.5:3b
   ```
3. 等待下载完成（约 2-4GB）

### 验证安装

运行 `3-验证-安装.bat`，看到模型列表说明成功。

---

## 第三步：启动服务

### 首次设置

1. 双击 `4-安装-依赖.bat`（安装服务端依赖）
2. 下载 ngrok：https://ngrok.com/download
3. 把 `ngrok.exe` 复制到此文件夹

### 每次使用

1. 双击 `5-启动-服务端.bat`
2. 等待显示 `Server running on port 3001`
3. 双击 `6-启动-内网穿透.bat`
4. 等待显示 `Forwarding https://xxx.ngrok.io`
5. **复制这个 ngrok 地址**

---

## 第四步：手机使用

1. 用华为浏览器打开：
   ```
   https://georgewhere.github.io/noval-AI-Assistant/
   ```
2. 点击右上角 ⚙️ 设置
3. 粘贴 ngrok 地址
4. 保存后开始使用

## 常见问题

### Q: Ollama 下载很慢怎么办？
A: 可以尝试科学上网，或者更换下载时间段。

### Q: 手机连不上？
A: 检查电脑的 `5-启动-服务端.bat` 和 `6-启动-内网穿透.bat` 是否都在运行。

### Q: 重启电脑后要重新设置吗？
A: Ollama 和模型只需安装一次。每次使用时只需重新运行启动脚本。
